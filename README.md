# Photo Style Templates

[简体中文](README.zh-CN.md)

70 independently copyable photo-editing Skills, including original instructions and licensed adaptations with per-entry authorship, pinned sources, license terms and modifications. Each folder includes bilingual workflow instructions, a structured recipe, preservation rules and acceptance criteria. 69 examples are ready and 1 are draft; status describes example review, not a live service or guaranteed output.

## Install and use

1. Choose a style below and copy its whole folder from skills into your Skill directory, such as ~/.codex/skills. Keep SKILL.md, recipe.yaml, provenance.json and LICENSE together. No script, dependency installation or API key is required.
2. Select the Skill in an assistant that supports Skills and reference-image editing, then supply a photograph you have permission to edit. Other assistants can read SKILL.md and recipe.yaml directly.
3. Inspect the source image first, perform the requested interpretation, and check the style's acceptance criteria. Your environment determines the available image model.

Identity, subject counts, structure and framing are protected by default; each Skill states its own permitted geometric changes. Both source and effect examples are AI-generated, not photographs of real people. Different models, settings and inputs do not guarantee identical results.

## Status and licensing

An example is ready only when both source and effect files exist and both have approved visual reviews in generation records. Missing images, missing reviews or unsuccessful reviews remain draft. Only existing images are linked. The [complete index](index.json) records machine-readable status.

## Maintenance

The 4 JSON files in data are the source of truth. After installing the pinned package.json dependencies, maintainers can run npm run build to reproduce documentation and the index from existing compressed examples and audit records, or node scripts/build.mjs --generation /path/to/generation to recompress external original outputs. Run npm run validate to check content, references, recipe parity, actual prompts, hashes and reviews; npm test covers packaging regressions. Examples are metadata-free 960×1200 WebP images fitted with contain to preserve the complete frame. The [generation ledger](docs/generation-ledger.json) retains every call, including rejected attempts; original PNG files are excluded. The builder only reads existing assets and contains no generation-service caller, provider configuration or keys. Skill users do not need maintenance commands.
